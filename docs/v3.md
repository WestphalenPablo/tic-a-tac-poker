# v3: installable app, touch drag and drop, hand reveal

**What:** the state of the repo at git tag `v3` builds on [v2](v2.md) (online rooms) with a client-only release: the game is an installable, offline-capable PWA, drag and drop works on touch, newly made hands are highlighted, and open tabs are told when a new version is deployed. The rules, `packages/game` and `packages/server` are unchanged.

**Contents at v3** (all in `packages/client`)
- **Hand reveal:** the cards of each newly made hand get an amber outline and pulse, one hand at a time; a pair outlines only its two matching cards. Joker-placed cards render identically to natural ones. See [changelog.md](changelog.md).
- **Update banner:** "A new version is available. Reload" when `version.json` shows a newer build than the running one; checked on focus and every 5 minutes, never reloads by itself. See [update-banner.md](update-banner.md).
- **PWA:** custom royal-flush icon (rendered from the UI styling by headless Chrome), web manifest, a service worker emitted per build for offline play, a header Install button and a self-made install banner (manual instructions on iOS). See [pwa.md](pwa.md).
- **Pointer-event drag and drop:** mouse, touch and pen through one path, with a ghost card, drop-target outline, snap-back on invalid drops and Escape to cancel; taps still select. Replaces the HTML5 drag and drop. The client package gained `vitest` and unit tests for the drag helpers. See [drag-drop.md](drag-drop.md).
- **Mobile layout:** hand labels moved below the card grid so the two boards stay aligned when labels wrap; long player names truncate.
- Docs: [voice-over-generation.md](voice-over-generation.md) records a parked idea (generated voice clips). `CLAUDE.md` now asks to monitor and report the Pages deploy after an authorized push.

**Verified at tag time**
- `pnpm typecheck` clean; `pnpm test`: 24 game, 5 client and 25 server tests pass; `pnpm build` succeeds.
- Headless Chromium against production builds (Playwright): mouse drag and drop flows, touch drag with real touch events (CDP), the PWA's service worker, offline reload and install banner/button with a synthetic install event, the boards staying aligned at 375 px with long labels, and no page errors.
- Live: the Pages deploys for the update banner, the PWA and the drag and drop all finished successfully and the site answers 200.

**Not verified:** a real install on Chrome, Android or iOS (including icon rendering and the install dialog); touch drag on real devices (iOS Safari especially) and haptics; how the installed app picks up an update across two real deploys; the Robber two-step and Joker drops driven by drag in a browser; drag and drop and the PWA during online games; the hand-reveal timing against voice clips.

**Version:** all four `package.json` files are `3.0.0`.

**Return to it:** `git checkout v3`.
