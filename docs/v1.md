# v1 — canonical baseline

**What:** the state of the repo at git tag `v1` is the first canonical version of the single-player MVP. Later work is measured against it.

**Contents at v1**
- `packages/game`: rules, reducer (`applyMove`), scoring, Easy/Hard bot. Joker/Robber ("MSN") and Classic modes.
- `packages/client`: React UI with drag and drop, gamepad, responsive layout, bot move animations, voice clips, 5-second first-draw ritual.
- Rules as implemented: `README.md`. Client changes: [changelog.md](changelog.md). Sounds: [sound-effects.md](sound-effects.md). First draw: [first-draw.md](first-draw.md).
- Still deferred: server, lobby, chat, multiplayer, turn timer.

**Verified at tag time:** `pnpm typecheck` clean; `pnpm test` 15/15 pass.

**Not verified:** in-browser behaviour, mobile layout, audio on all browsers. The untracked `sounds/pt/new/` directory is not part of v1.

**Version:** all three `package.json` files are `1.0.0`.

**Return to it:** `git checkout v1`.
