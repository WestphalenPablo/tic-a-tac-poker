# v2 — online rooms

**What:** the state of the repo at git tag `v2` adds online play on top of the [v1](v1.md) single-player baseline: two people play each other through a shared link, against an authoritative server. It was deployed and played end to end on the live site before tagging.

**Contents at v2**
- `packages/game`: unchanged rules and bot, plus `protocol.ts` (wire messages, `parseClientMessage` validation, `viewFor` per-seat views that hide the deck).
- `packages/server` (new): Node + `ws`, in-memory rooms, reconnect with a per-seat token, rematch, Origin allowlist, `/health`. Bundled to `dist/index.cjs` with esbuild.
- `packages/client`: mode menu after the tutorial, name prompt, share-link modal (copy, native share where available), `/room/{id}` URLs with the GitHub Pages `404.html` fallback, names on both sides, rematch, reconnect UX, and a "waking up the server" notice for the sleeping free tier.
- Deployment: client on GitHub Pages (`VITE_SERVER_URL` repo variable); server on Render's **free** plan via `render.yaml`, at `https://tatp-server.onrender.com`.
- Docs: [multiplayer-server.md](multiplayer-server.md) (design, protocol, deploying), [online-rooms-ui.md](online-rooms-ui.md) (client flow, verification), [github-pages.md](github-pages.md), [tutorial.md](tutorial.md).
- Still not built: lobby/matchmaking, chat, turn timer, persistence (a server restart or sleep drops rooms), per-IP rate limiting, gamepad support in the menus.

**Verified at tag time**
- `pnpm typecheck` clean; `pnpm test`: 24 game tests and 25 server tests (including real-`ws` clients); `pnpm build` and the server bundle build.
- Locally in a real browser (Playwright, two isolated profiles): create and join, a full game with Joker, Robber and plain cards, mid-game reload, rematch, a third player refused, leaving closing the room, and the sleeping-server notice.
- Live: Render build and deploy succeeded; `/health` returns `ok`; a WebSocket upgrade is accepted from the Pages origin and refused (403) from another; the Pages bundle contains the server URL; and the owner played a room end to end on the live site, including opening the shared link.

**Not verified:** `navigator.share` on a real phone, mobile layout of the new modals, Portuguese wording by a native reader, reconnect after a real network drop (only page reloads were tried), Render build filters, how long a cold start really takes, whether open WebSockets keep the free service awake, and sessions longer than a few minutes through Render's proxy.

**Version:** all four `package.json` files are `2.0.0`.

**Return to it:** `git checkout v2`.
